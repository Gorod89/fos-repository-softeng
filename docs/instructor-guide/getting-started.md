# Запуск курса

1. Создайте семестровую ветку от проверенного тега.
2. Выполните `uv sync --frozen && make validate && make test && make docs`.
3. Проверьте каждый starter на чистой машине или в Codespaces.
4. Создайте отдельные template-репозитории заданий.
5. Храните эталонные решения и закрытые тесты только в приватном пространстве.
6. Проведите пилот задания не менее чем с одним преподавателем и одним студентом.

Перед началом потока зафиксируйте дедлайны, правила повторной сдачи, доступные
адаптации и контакт для ответственного раскрытия уязвимостей.
