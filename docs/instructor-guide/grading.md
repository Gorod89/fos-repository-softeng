# Проверка и защита

Сначала учитываются детерминированные результаты тестов, затем преподаватель
оценивает инженерное решение и анализ. Каждая ручная корректировка должна
содержать ссылку на критерий и короткое обоснование.

Защита проверяет перенос знания. Студент получает одно небольшое изменение:

- новый формат данных;
- дополнительный endpoint;
- иной критерий сортировки;
- ограничение памяти;
- отказ одного сервиса;
- новый конфликт Git.

Изменение должно укладываться в 10–20 минут и быть равноценным для разных
студентов. Оцениваются диагностика, план, безопасное изменение и объяснение,
а не скорость набора кода.
