# GitHub Classroom

Для каждого `assignments/M*-starter` создается отдельный template-репозиторий.
Так студенты получают собственную историю, issues и pull requests, а основной
репозиторий остается канонической версией курса.

Рекомендуемый autograding:

- публичные тесты запускаются при каждом push;
- закрытые тесты добавляются Classroom и не копируются в открытый starter;
- автоматическая доля составляет 40–60% лабораторной;
- ограничение времени workflow — 10 минут;
- `GITHUB_TOKEN` получает только `contents: read`;
- итоговая обратная связь ссылается на критерии YAML-рубрики.

Нельзя помещать эталонное решение в историю starter-репозитория: удаленный файл
остается доступен в предыдущих коммитах.
