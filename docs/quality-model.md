# Модель качества курса

Курс считается зрелым, когда:

- новый пользователь получает рабочую среду менее чем за 10 минут;
- каждый программный КИМ имеет публичные тесты и контракт закрытых проверок;
- обратная связь CI приходит не позднее 10 минут;
- сумма баллов и трассировка результатов проверяются автоматически;
- данные имеют версию, источник и контрольную сумму;
- правила ИИ прозрачны, а авторство подтверждается инженерным процессом;
- каждый поток привязан к воспроизводимому релизу;
- изменения проходят pull request и обязательные проверки.

Качество измеряется после каждого потока и отражается в changelog. Чек-лист
не является доказательством сам по себе: каждый пункт должен иметь автоматическую
проверку, артефакт или ответственное лицо.
