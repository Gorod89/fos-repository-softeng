# Разработка программных решений для систем ИИ

Это открытая исполняемая образовательная платформа: материалы курса, задания,
машиночитаемые рубрики и автоматические проверки образуют один версионируемый продукт.

## Две траектории

=== "Студенту"

    1. Откройте [быстрый старт](student-guide/getting-started.md).
    2. Пройдите задания M1–M8 по порядку.
    3. Сверяйтесь с [единой моделью оценивания](student-guide/assessment.md).
    4. Заполняйте `AI_USAGE.md` в каждом задании.

=== "Преподавателю"

    1. Создайте задания из starter-каталогов через GitHub Classroom.
    2. Подключите закрытые тесты отдельно от открытого репозитория.
    3. Используйте YAML-рубрики как единый источник баллов.
    4. Выпускайте семестровый релиз и анализируйте обезличенные результаты.

## Проверяемые гарантии

- сумма компонентов курса равна 100 баллам;
- форма аттестации — «зачет», шкала — «зачтено / не зачтено»;
- каждый результат обучения подтвержден хотя бы одним КИМ;
- восемь starter-проектов имеют одинаковый контракт запуска;
- данные версионированы контрольной суммой;
- документация и спецификация проверяются в CI.

```bash
uv sync --frozen
make validate
make test
make docs
```
