# Задания и траектория

| Модуль | Артефакт | Основной результат |
|---|---|---|
| M1 | Архитектурное описание и ADR | Обоснование границ и компромиссов |
| M2 | ETL и схема данных | Идемпотентная загрузка в PostgreSQL |
| M3 | Восстановленная история Git | Rebase, bisect, recovery и командная работа |
| M4 | Качественный Python-пакет | Тесты, типизация, конфигурация, логи |
| M5 | KNN на NumPy | Корректность, векторизация, память |
| M6 | Воспроизводимый EDA | Качество данных, статистика, визуализация |
| M7 | FastAPI-сервис | Контракт, валидация, ошибки и тесты |
| M8 | Контейнерный релиз | Docker Compose, healthcheck и CI/CD |

Модули идут по нарастающей сложности. M1 не требует развертывания в облаке:
Docker и CI/CD оцениваются в M8. Публичные тесты дают быструю обратную связь,
но не раскрывают все граничные случаи.

Для каждого задания:

1. создайте feature branch;
2. прочитайте `README.md` и рубрику;
3. зафиксируйте план в issue или ADR;
4. реализуйте решение и тесты;
5. заполните `AI_USAGE.md`;
6. откройте pull request и дождитесь CI;
7. пройдите защиту с небольшим изменением условия.
