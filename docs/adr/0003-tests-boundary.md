# ADR-0003: граница публичных и скрытых тестов

- Статус: принято
- Дата: 2026-07-29

## Контекст

Студенту нужна быстрая обратная связь, но публикация всех тестов поощряет
подгонку и раскрывает граничные случаи.

## Решение

Starter содержит только публичные контрактные тесты. Скрытые тесты и эталонные
решения хранятся отдельно и подключаются через GitHub Classroom. Автопроверка
дает 40–60% баллов, остальное подтверждается ревью и защитой.

## Последствия

Открытый репозиторий нельзя считать полным комплектом преподавателя. Любой
закрытый тест должен проверять опубликованное требование, а результат может
быть пересмотрен вручную при корректном альтернативном решении.
