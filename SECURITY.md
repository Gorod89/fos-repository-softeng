# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются для текущего семестрового релиза и ветки
`main`.

## Сообщение об уязвимости

Не создавайте публичный issue с рабочим эксплойтом, токеном или персональными
данными. Используйте GitHub Private Vulnerability Reporting, если функция
доступна, либо приватный канал сопровождающего курса.

Укажите затронутый файл и версию, условия воспроизведения, влияние и безопасный
минимальный пример. Не атакуйте чужие аккаунты и внешнюю инфраструктуру.

Мы подтверждаем получение, оцениваем риск и согласуем срок публикации. Учебные
намеренные дефекты маркируются явно и не должны быть пригодны для реальной атаки.

Секреты хранятся в переменных окружения или GitHub Secrets. Файлы `.env`,
закрытые тесты и реальные учетные данные не коммитятся.
