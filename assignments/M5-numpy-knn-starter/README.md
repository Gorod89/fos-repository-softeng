детерминированное разрешение равенства голосов и исследуйте время и память.

notebook.

```bash

```

Публичные тесты проверяют интерфейс и базовые случаи. Закрытые — граничные
случаи, воспроизводимость, запрет на хардкод и ограничения памяти. На защите
добавляется новая метрика расстояния.
