# M6. Pandas и воспроизводимый EDA

Постройте пайплайн загрузки, проверки качества, очистки и агрегирования данных.
Исходный CSV не изменяется; графики сохраняются с подписями и строятся
детерминированно. Для статистического вывода укажите размер эффекта и ограничения,
а не только p-value.

```bash
make install
make test
```

На защите требуется добавить новый срез данных. Пиксельное совпадение графиков не
оценивается: проверяются данные, подписи и воспроизводимость артефакта.
