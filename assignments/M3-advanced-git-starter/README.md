# M3. Продвинутый Git

История создается генератором и не хранится вложенным `.git` в основном курсе.

```bash
make install
make scenario
cd workspace
git log --graph --oneline --all
```

В одноразовом репозитории выполните rebase, cherry-pick, поиск регрессии через
bisect и безопасное восстановление через reflog. Проверяется граф и содержимое,
а не конкретные SHA. На защите вы получите новый конфликт.

Повторный `make scenario` намеренно откажется перезаписывать существующий
`workspace`: сначала перенесите результаты или удалите каталог осознанно.
