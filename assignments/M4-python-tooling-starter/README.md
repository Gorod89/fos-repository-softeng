# M4. Инженерное качество Python

Развивайте единый небольшой сервис обработки заказов: добавьте конфигурацию,
валидацию, обработку ошибок, структурированные логи и тесты без доступа к сети.

```bash
make install
make check
```

Готово, когда публичные тесты проходят, критическая логика покрыта тестами,
секреты не появляются в логах, а ошибки имеют понятные типы. На защите меняется
одно правило расчета.
