# M1. Архитектура ИИ-приложения

Спроектируйте сервис классификации обращений без преждевременного требования
Docker, Kubernetes или публичного облака. Опишите измеримые требования,
границы компонентов, интерфейсы и минимум два ADR.

## Запуск

```bash
make install
make test
```

## Готово, когда

- `architecture.yml` проходит публичный валидатор;
- у каждого компонента одна ясная ответственность;
- требования по задержке, доступности, безопасности и наблюдаемости измеримы;
- диаграмма и ADR согласованы с выбранными интерфейсами;
- заполнен `AI_USAGE.md`.

Автопроверка дает 2 из 6 баллов. На защите преподаватель изменит одно
нефункциональное требование; нужно объяснить влияние на архитектуру.
