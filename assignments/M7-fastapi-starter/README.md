# M7. REST API на FastAPI

Развивайте API прогнозов: добавьте новый endpoint, единый формат ошибок,
валидацию и тесты успешных и ошибочных сценариев. Сервис по умолчанию не требует
внешней сети или базы данных.

```bash
make install
make test
make run
```

Готово, когда `/health` стабилен, OpenAPI соответствует поведению, ошибки
предсказуемы, а блокирующие операции не выполняются в async-обработчике.
На защите добавляется небольшой endpoint.
