# Starter-проекты

Каждый каталог — канонический шаблон отдельного задания для GitHub Classroom.
Закрытые тесты и эталонные решения в открытый репозиторий не входят.

Общий контракт:

```bash
make doctor   # проверить инструменты
make install  # установить фиксированные зависимости
make test     # запустить публичные тесты
make check    # выполнить все локальные проверки
```

Starter должен запускаться менее чем за 10 минут, работать без платного сервиса,
не содержать секретов и давать понятную обратную связь на русском языке.

| Каталог | Модуль |
|---|---|
| `M1-architecture-starter` | Архитектура |
| `M2-databases-starter` | PostgreSQL и ETL |
| `M3-advanced-git-starter` | Продвинутый Git |
| `M4-python-tooling-starter` | Инженерные инструменты Python |
| `M5-numpy-knn-starter` | NumPy и KNN |
| `M6-pandas-eda-starter` | Pandas и EDA |
| `M7-fastapi-starter` | REST API |
| `M8-docker-starter` | Docker и CI/CD |
