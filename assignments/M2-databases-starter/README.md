# M2. PostgreSQL и ETL

Завершите схему и ETL-пайплайн для небольшого учебного набора. Повторный запуск
не должен создавать дубликаты. Сравните последовательную и конкурентную загрузку:
на малых данных ускорение не является обязательным результатом.

```bash
make install
make test
docker compose up -d db
```

Готово, когда ограничения схемы работают, ETL идемпотентен, запросы проверяемы,
а `EXPLAIN ANALYZE` интерпретирован без выдуманных выводов. На защите меняется
формат одной входной колонки.
